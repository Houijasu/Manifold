# Eonego NNUE parity fixtures

`eonego_refset_10k.fen` is a deterministic corpus of 10,000 legal positions
generated by `harness/generate_eonego_refset.py` with Python 3.12,
python-chess 1.11.2, and seed `0xE0E60`. Its leading records cover both sides
to move, promotion and promoted material, standard and Chess960/X-FEN
castling rights, en passant, endgames, and all eight NNUE occupancy buckets.

`eonego_refdump_10k.bin` is generated test-fixture output from Eonego's
`dumpft` command. Each input FEN produces one 1,034-byte little-endian record:
`bucket u8`, `stm u8`, `psqtInternal i32`, `evalInternal i32`, and
`ft[1024]`.

Reference SHA-256 values:

- Eonego executable: `C3D3E66AC37097BF59497C2315C4F43E0623CE03D5CF67AAD8A17BE8E00D8758`
- `main.nnue`: `E8449B689E26E40DFD8FAC0423E7825377AFDE8B7D40FC14BFB96DFA32FF908A`
- FEN corpus: `C79EA207C53CAEAABF897099637B52317AE5267EEBBEE49B29DFC0E1BB12D74C`
- Reference dump: `BC40C4D88BD34A8CCA6507153C69ED1EF281DD37E60D9828C4D5A59F690DBD89`

Regenerate from the Manifold repository root:

```powershell
& 'C:\Users\Samaritan\Projects\Eonego\.venv\Scripts\python.exe' `
  harness\generate_eonego_refset.py

& 'C:\Users\Samaritan\Projects\Eonego\Eonego\bin\Release\net10.0\win-x64\publish\Eonego.exe' `
  dumpft `
  --net 'C:\Users\Samaritan\Projects\Eonego\nets\main.nnue' `
  --in crates\mf-nnue\tests\data\eonego_refset_10k.fen `
  --out crates\mf-nnue\tests\data\eonego_refdump_10k.bin
```
