## Investigate items (not planned; ceiling-named)

- **AVX-512 forward backend** (`simd.rs` backends are Scalar/Avx2/Avx2Vnni): only worth it if `is_x86_feature_detected!("avx512f" && "avx512vnni")` is true on target hardware; measure with `harness/nps_compare.py` before committing to a port. Downclocking can erase gains on some Intel parts.
- **`rebase_halfka` scalar loop** (accumulator.rs ~853-877): dump the asm under `target-cpu=native` first; if LLVM already vectorized it, close the item. Ceiling: 2 KB of i16 math per mirror-held king move, 69.6% of Finny-served king moves.
- **MoveList 256 cap on parser-accepted overloaded boards** (movegen.rs:14-47): three constructed max-mobility boards (16 queens + knights) stayed under the cap; mechanism certain, exploit not demonstrated. Hardening is a one-line constant bump if ever tripped — wait for evidence.
