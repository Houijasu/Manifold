Pyrrhic
Source repository: https://github.com/AndyGrant/Pyrrhic

The following Manifold modules contain code derived from Pyrrhic:

- crates/mf-tb/src/chess.rs, derived from Pyrrhic/tbchess.c
- crates/mf-tb/src/probe.rs, derived from Pyrrhic/tbprobe.c

Pyrrhic is itself derived from Fathom (https://github.com/basil00/Fathom) and
the original Syzygy probing code by Ronald de Man
(https://github.com/syzygy1/tb).
